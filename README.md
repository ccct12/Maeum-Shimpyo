# 마음쉼표

마음이 힘든 사람이 가까운 정신건강의학과 의원·병원과 무료 공공 상담기관을 지도에서 찾고, 우울·불안 자가검진을 무료로 해 볼 수 있는 모바일 우선 웹사이트입니다.

- 주소: https://ccct12.github.io/Maeum-Shimpyo/
- 화면: 지도 / 자가검진(PHQ-9, GAD-7) / 마음 쉬기(숨 고르기·배로 숨쉬기·감각으로 돌아오기·몸 풀기·안심 문구) / 마음 통계 / 처음이라면
- 모든 화면에 위기상담 번호 고정: 109 자살예방 상담전화, 1577-0199 정신건강 위기상담

## 구조

```
index.html              화면 뼈대
assets/config.js        카카오 JavaScript 키, 데이터 주소 (여기만 고치면 됨)
assets/app.js           지도·목록·진료 상태 계산·자가검진·통계 차트
assets/style.css        모바일(기본) / PC(900px 이상) 레이아웃, 다크 모드
data/stats.json         통계 페이지 데이터 (구글 시트 통계_지표에서 추출)
data/facilities-fallback.json  시트 연결이 안 될 때 쓰는 공공데이터 좌표 사본
```

## 데이터 흐름

1. 구글 시트 `기관_마스터`가 원본입니다. Apps Script가 매일 새벽 좌표가 없는 행을 TMAP으로 채웁니다.
2. Apps Script 웹 앱(`?type=facilities`)이 `노출=TRUE`인 기관만 JSON으로 내보냅니다.
3. 사이트는 그 JSON을 읽고, 거리·진료 상태는 이용자 브라우저 안에서만 계산합니다.

TMAP 약관상 TMAP으로 받은 좌표는 24시간 넘게 저장해 쓸 수 없어서, 저장소에는 공공데이터가 준 좌표만 넣습니다(`facilities-fallback.json`).

## 개인정보

- 회원가입·로그인 없음
- 위치와 자가검진 응답은 이 기기 밖으로 보내지 않고 저장하지 않음
- 접속 기록·분석 도구 없음 (붙일 때 개인정보 검토 다시 필요)

## 공개 전 확인할 것

- [ ] 자가검진 문항을 PHQ-9·GAD-7 공식 한국어판 문구로 교체
- [ ] 의료기기(소프트웨어) 해당 여부, 위치정보법, 의료법(광고) 검토
- [ ] 처음이라면 안내 글, 마음 쉬기 문구·안내 정신건강 전문가 검수
- [ ] 숨 참기가 있는 호흡법(4-7-8, 박스)은 전문가 검토 후 추가 여부 결정
- [ ] 심평원 의료기관별상세정보서비스로 의원·병원 진료시간 추가

## 출처

건강보험심사평가원 병원정보서비스, 전국건강증진센터표준데이터(각 지자체), 국립정신건강센터 정신건강 관련기관 정보, 전국민 마음투자 지원사업 제공기관 목록, 국민건강보험공단, 질병관리청, 보건복지부, 한국청소년상담복지개발원, 서울특별시. 일부 좌표: TMAP.
